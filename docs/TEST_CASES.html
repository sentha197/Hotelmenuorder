DineQR: Test Cases

Manual test cases for the whole Hotelmenuorder application: the customer app (Flutter), the customer web app (React), the admin app (Flutter), the shared business layer and the DineQR API (ASP.NET Core + PostgreSQL). Rules, limits and error codes come from the source code (backend/src/DineQR.Api, packages/dineqr_core) and the READMEs.

Conventions: money in the API is integer paise (₹1 = 100); percentages are basis points (5% = 500) and round half-up. Example settings used in pricing cases: GST 5%, service charge 10%; adjust the expected figures if your restaurant uses other rates. Status and notes you enter are saved in this browser only (localStorage); use Export CSV to share a test run.
